# SillyTavern JS

расширение для [SillyTavern](https://github.com/SillyTavern/SillyTavern), которое заставляет работать интерактивные HTML/CSS/JS‑плашки на регексах.


---

## ⚠️ безопасность — прочитайте перед установкой

по умолчанию SillyTavern **вырезает** теги `<script>` из сообщений через DOMPurify. это защита: чтобы вредоносный контент не выполнил произвольный JavaScript в вашем браузере.

**это расширение сознательно отключает эту защиту** — оно извлекает `<script>` из сообщений и выполняет их заново. Без этого интерактивные плашки не работают.

что это значит:

- ✅ если вы используете **свои** или **доверенные** пресеты — всё в порядке.
- ⚠️ если вы откроете **чужую** карточку персонажа со встроенным `<script>`, он **выполнится** и получит доступ к странице SillyTavern (localStorage, настройки, API‑ключи, сетевые запросы).

**ставьте только тот контент, которому доверяете.** расширение не крадёт данные само по себе, но снимает «песочницу», и тогда опасным становится любой недоверенный JS в сообщениях.

## установка

### через Git

1. в SillyTavern: **Extensions → Install Extension**
2. вставьте URL этого репозитория:
   ```
   https://github.com/MiNtorikaSoul/SillyTavern-JS-support
   ```
3. нажмите Install и перезагрузите страницу (Ctrl+F5).

### вручную

скопируйте `manifest.json` и `index.js` в папку:

```
SillyTavern/data/<ваш-юзер>/extensions/sillytavern-js/
```

перезагрузите страницу.

после загрузки появится уведомление **«SillyTavern JS v1.0 loaded»** и кнопка **ST‑JS Debug** в правом нижнем углу (для отладки).

## что делает расширение

- перехватывает `<custom-style>` / `<style>` и чинит CSS, который ломает парсер SillyTavern (inline‑комментарии `/* ... */`, флаг `i` в селекторах, лишние `<br>`) — иначе в чате появляется `CSS ERROR: ...`.
- извлекает `<script>` из сообщений и выполняет их в контексте своего виджета (поддержка `document.currentScript.parentElement`).
- синхронизирует классы: SillyTavern добавляет префикс `custom-` к CSS‑селекторам, а скрипты пресетов работают с «голыми» классами — расширение зеркалит их в обе стороны (цвета, темы, переключения работают).

---

## совместимость

- SillyTavern (актуальные версии).
- работает с пресетами, использующими `<style>`, `<script>` и `document.currentScript` внутри regex‑replace.

---

## отладка

кнопка **ST‑JS Debug** в правом нижнем углу показывает количество необработанных скриптов, статус DOMPurify‑хука и последние ошибки/логи.
